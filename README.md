# TheLook E-commerce — Mini Project SQL
My SQL learning projects using Google BigQuery

## Tujuan
Menganalisis produk, pelanggan, pesanan, dan nilai penjualan menggunakan SQL di Google BigQuery.

## Dataset
`bigquery-public-data.thelook_ecommerce`

Tabel yang digunakan:
- `products`
- `users`
- `orders`
- `order_items`

## Pertanyaan bisnis
1. Menampilkan 20 produk pertama.
2. Mencari produk dengan retail_price di atas 100.
3. Menghitung jumlah produk per kategori.
4. Menggabungkan pelanggan dan pesanan.
5. Menghitung total nilai penjualan per kategori.

## Insight
1. Berdasarkan hasil analisis, kategori dengan jumlah produk terbanyak adalah intimates, dengan jumlah 2363 produk. Hal ini     menunjukkan bahwa kategori tersebut memiliki variasi produk yang relatif besar dalam katalog.
2. Kategori dengan total nilai penjualan tertinggi adalah outerwear & coats, dengan nilai 1292984.428926468. Kategori tersebut memiliki nilai transaksi terbesar berdasarkan data yang dianalisis.
